// moet ook hier wegblijven, anders zet Syncthing het binnen seconden op een pc. Plus de vluchtige bestanden uit het plan § 4.3.
//
// HOE. De vault-.stignore is een symlink van claude naar DIT bestand in /app (root, alleen-lezen): socev kan de wortel niet
// schrijven en dit bestand ook niet. run.sh zet de symlink, toetst dit filter tegen bisync-filter.txt (syncthing-filter-toets.sh,
// met een wegwerp-Syncthing) en start Syncthing alleen bij groen. Syncthing-taal: de eerste regel die past wint; ! = wel mee;
// (?i) = hoofdletterongevoelig; een regel zonder / geldt op elke diepte en voor een map met alle inhoud; geen regex.
// Bewuste verschillen met bisync (de toets kent ze): (1) Syncthing laat MEER weg (blok A, plus elke naam die eindigt op
// punt of spatie, en een bestand dat zo heet als een config-map); (2) een naam met niet-ASCII vóór een eerdere punt én in de
// laatste extensie (a.ü.b.mdé) gaat via Syncthing wél mee, tenzij die extensie gevouwen een code-extensie is: globs kunnen "na
// de laatste punt" niet uitdrukken. Alleen ı en ſ vouwt Windows naar ASCII (".msı" opent als .msi; Fable wv813 #1); elke
// code-extensie met ı/ſ staat daarom hieronder apart en valt altijd.
// Niet met de hand aanpassen zonder bisync-filter.txt en syncthing-filter-toets.sh mee te nemen.
